# Visual sequence notes

Use after the narration is approved, or for an explicitly authorized non-production test. Read [visual DNA](../visual-dna.md). Record useful decisions rather than filling a universal template. No fixed scene count, character ratio, mandatory visual type or sentence-to-image mapping applies.

- Episode/test identity, actual narration version and selected spans:
- Current original Chibi 2D visual DNA, period/place continuity, source/rights ledger and internal provenance rules (no visible AI/illustration disclosure labels):
- What changes in the audience's understanding across this sequence:

For each natural scene, record whichever items matter:

- Narration span and scene objective.
- Primary subject; reason for this representation, distance/viewpoint and detail density.
- People: absent, listed cast or contextual inhabitants; action/emotion/viewpoint/story value if present.
- The visible state/relationship and what the image lets the viewer understand.
- Previous/next-scene link: geography, object state, motif, branch or explanatory connection.
- Evidence, assumptions, branch and scale/time limitations.
- Camera/hold and exact text/readability when useful.
- Sound intent when useful: speech priority, ambience/illustrative sound, music state and the reason for change; no compulsory foley or beat grid.
- Supported Chibi human action, object, environment or sourced diagram; original keyframe or suitable unchanged-state full-image reuse, and why. Footage records apply only to existing episodes with a saved legacy route.

Review the whole sequence: which explanation needs more time, which repeated framing is useful or stale, whether a person replaces the real subject, and whether independent scenes share the same world/style. Then inspect actual images and record corrections and remaining limits. Record prompt-only, image-reviewed or motion-reviewed status precisely; none implies production approval automatically.

- Camera intent/direction and crop safety; keep pan/zoom only where they help this scene.
- Reuse source and visible-state match; review duration share and nearby returns using image-reuse-qa.json.
