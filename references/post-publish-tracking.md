# Post-publish tracking

Keep one copy of this file per channel at `research/<channel-id>/post-publish-tracking.md` (or in the channel folder the user names). Numbers come only from YouTube Studio screenshots the user provides. Do not estimate missing cells; write `not provided`.

Read this file before choosing the next topic (see topic-research.md). A video that tripped a threshold is a lesson for the next title, thumbnail or opening, not only for itself.

## Thresholds

| Check | Threshold | Action |
|---|---|---|
| CTR (impressions click-through rate) | below 2% | Revise title and/or thumbnail; re-check the title's main phrase with autocomplete |
| Viewers remaining at 0:30 | below 50% (more than half lost) | Revise the opening: start from something the viewer already knows |
| Average view duration | below 30% of video length | Review the middle: repeated ideas, hedging, missing open question |
