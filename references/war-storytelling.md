# Documentary war storytelling

Use the active channel documentary skill and war specialist. Orient terrain, time, parties and available information, then reconstruct approach, combat action, response, options, cost and actual outcome. Use maps to explain geometry; show supported combat and crew actions as well. Source technical and casualty claims with definitions. Never invent thoughts/testimony. Include civilian effects where material. Documented history is standard; alternate history is optional and explicitly framed. The old intervention template is not required.
