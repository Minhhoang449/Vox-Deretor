Pass matching `--query-language` and `--relevance-language`. Do not substitute Vietnamese discovery for English or Japanese topics. Record any deliberate cross-language scan separately with `--cross-language-note`. Choose a promise supported by the actual episode evidence and check comparison feasibility only when contrasting outcomes. YouTube Data API searches are discovery, not factual or retention evidence. Verify mechanisms and claims independently. Never print .env keys.

Then plan new main episodes using plan_runtime.py: 8–16 minutes. Use the matching voice/language calibration for a provisional speech budget and write continuous narration. Do not pad; preserve approved targets and explicit exceptions.
4. Apply Story execution in scripting-dna.md, including the evidence-based viewer-question path and title/thumbnail/opening alignment. Run the red-pen → edit fact-check → channel-voice/naturalness → contextual pattern check → second red-pen loop in [editorial-review-loop.md](editorial-review-loop.md). Then complete separate story and retention passes on the full actual version with speech source/fingerprint; report /16 and /10, channel-fit evidence and limits. Mark useful verified progress by roughly 0:30; do not add a fixed cliffhanger, chapter or interruption quota. Do not apply universal banned-word filters. Obtain narration approval before beats and record that actual approval with narration_lock.py as described in narration-review.md.
5. Read visual-dna.md, imagegen-stills.md and skills/vox-visual-direction/SKILL.md. Resolve the channel's visual_dna from `channels.py show` (all six channels use original Chibi 2D with supported human action and explanatory graphics). Build the visual bible and beat map using meaningful narration spans, coherent period/place/state, useful maps/diagrams/comparisons and supported actions. Review the beat map and needed cast.
6. Choose music from D:\Music and set bgm_path. Use voices.md and narration-review.md. Generate native configured TTS from approved beats and measure duration before images. Listen to the automatically exported review/narration copy, including the consequential middle and ending, before producing all images. Keep OmniVoice 0.9 / 32 steps, VieNeu v3 native 1.0, and 0.8-second full-stop pauses including Japanese 。. Preserve explicit episode overrides. Revise/reapprove narration if timing misses; no stretching or padding.
7. Use scripts/codex_prompts.py <episode> to export prompts for Codex imagegen. Generate images in the selected channel’s configured style from verified sources; do not search for video, use video montage or invent documentary evidence. Do not add user-visible AI/illustration disclosure labels to stills or rendered video; keep factual role and provenance in internal records. Review each image, register stills and follow image-reuse.md, exact localized in-scene text, sourced diagram labels, phone/crop QA and visible animation.keyframe actions. Still camera movement does not create missing physical events or character motion.
8. Read render-defaults.md for every render/continuation. Assemble new episodes with pipeline: local and visual_mode: revideo_stills using FFmpeg/NVENC, two workers, balanced camera and valid cache reuse. This route contains generated still images only. Caption QA comes before rendering; WhisperX aligns approved text and speech; SRT and static ASS share captions-timeline.json. Resolve structural/content/coverage errors and review estimates/reading-speed warnings. Listen and inspect the rendered still sequence before claiming delivery quality.
9. After story lock finalize and recheck the packaging concepts researched before narration; do not begin title/thumbnail research here for the first time. Select catalog playlists and run export_youtube.py. New thumbnails are 1280x720 and use original Chibi 2D, purposeful human action or explanatory graphics and exact localized text/readability. Public descriptions omit source sections by default; retain evidence internally and required asset/license attribution. Brand graphics are not fixed thumbnail templates. Local export does not publish.
